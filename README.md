# 📦 פרויקט קטלוג הסקילים של Hermes Agent

פרויקט מובנה ומקיף המרכז את המידע המלא, הנתונים הטכניים והקישורים של כל **116 הסקילים** המותקנים והפעילים במערכת ה-Hermes שלך.

---

## 📂 קבצי המידע בפרויקט:

1. **[skills_catalog.json](./skills_catalog.json) (בסיס נתונים מובנה):**
   קובץ JSON מובנה המכיל את הפרטים המלאים של כל הסקילים: שם, תיאור, גרסה, פלטפורמות, תגיות, נתיב מקומי וקישור קוד מקור (Git Link) בגיטהאב. מתאים לקריאה ושימוש אוטומטי של סוכנים אחרים ושאילתות מהירות.
   
2. **[skills_catalog.md](./skills_catalog.md) (קטלוג ויזואלי ומדריך שימוש):**
   מסמך Markdown מעוצב ומפורט המציג את כל הסקילים בחלוקה ל-21 קטגוריות פונקציונליות בעברית. כל סקיל כולל תיאור, גרסה, תגיות, קישורי גיט ישירים לקובץ המקור בגיטהאב, ומדריך התקנה ושימוש מעשי מפורט.

## 🛠️ שימוש וניווט מהיר:
הקטלוג מאפשר לך ולקאסי לחפש סקילים קיימים (כמו מדע נתונים, עיצוב פרונטנד, מדיה, אוטומציה וכו') ולהפעיל אותם בצורה חלקה בטרמינל או בצ'אט באמצעות הפקודות:
* `/skill <name>` - טעינת סקיל במהלך שיחה.
* `hermes --skills <name>` - הרצת סקיל מהטרמינל.
